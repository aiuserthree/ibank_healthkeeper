🐔 Sunny Side Farm

Run the egg business. Sell crates, automate the farm, unlock new areas.

  1. Walk to a coop to collect eggs.
  2. Drop them at the packing machine (left side). 3 eggs make a crate.
  3. Grab crates (right side) and stock the sales counter before customers lose patience.
  4. Stand on a glowing pad to spend coins on upgrades.

Move: WASD / arrow keys, or drag anywhere.

This game needs WebGL, which isn't available in this browser.
