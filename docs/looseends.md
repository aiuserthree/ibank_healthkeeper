# 실타래 풀기 (`looseends`)

수틀에 걸린 줄의 핀을 빈 구멍으로 옮겨, 엉킨 줄을 하나씩 풀어내는 퍼즐. 규칙을 참고해 새로 만든 오리지널 구현이며, 코드 · 그림(캔버스 드로잉) · 퍼즐 배치는 모두 직접 만든 것이다. 외부 이미지 · CDN 의존 없음.

## 규칙

- 판 둘레(와 안쪽)에 구멍이 있고 줄마다 양 끝 핀이 구멍에 걸려 있다. 줄은 위아래 순서가 있다.
- 어느 줄의 핀이든 빈 구멍으로 끌어 놓으면 한 수(1 이동). 옮긴 줄은 맨 위로 올라간다. 위에 얹힌 줄이 없는 줄(흰 테 핀)은 그냥 옮겨진다.
- **꼬임(2026-11-21)**: 위에서 덮고 있는 줄이 있는 줄을 옮기면, 덮고 있던 줄(과 이미 감긴 줄)마다 감긴 수가 핀이 돈 방향으로 ±1 바뀐다(한 쌍에 최대 3). 같은 쪽으로 또 돌리면 더 감기고, 반대쪽으로 돌리면(방금 수를 거꾸로 하면) 풀린다. 위 줄을 돌려서 풀 수도 있다. 덮인 핀을 집으면 얽힌 줄이 주황으로 깜박이고, 놓을 구멍을 고르는 동안 꼬일 줄을 미리 보여 준다. 감긴 쌍은 꽈배기 매듭과 ↻/↺ 감긴 수로 보인다.
- 모든 줄이 서로 엇갈리지 않고 **감긴 쌍도 없을 때** 한꺼번에 빠지며 클리어된다. 그 전까지 모든 줄과 핀은 판에 남는다.
- 목표 수 = 「깔끔한 수」(어느 쌍의 감김도 늘리지 않는 수)만으로 푸는 최소 수 — 본편 40판 목표는 꼬임 규칙 전과 같다. 일부 판(7·9·12·13·19·25)은 꼬임을 일부러 쓰면 한 수 짧게 풀린다(「꼬임 지름길」, ★3 그대로).
- 별: 이동 수가 목표 이하면 3개, +2 이내 2개, 그 밖에 1개.
- 끝없는 실 9판째부터 홀수 판과, 오늘의 퍼즐(날짜 씨앗의 2/3)은 덮인 줄 하나를 뺀 「처음부터 꼬인」 상태로 시작할 수 있다.

## 기능

- 본편 40단계(5개 장 · 별 120개), 퍼즐 지도(`실타래 길`: 지도 · 오늘 · 실 · 끝없는 실 탭).
- 오늘의 퍼즐(한국 날짜 씨앗 · 모두 같은 판 · 연속 일수), 끝없는 실(풀 때마다 새로 만들고 점점 어려워짐).
- 되돌리기(무제한), 다시 하기, 힌트(깔끔한 풀이 → 꼬임까지 쓴 풀이 → 그래도 없으면 되돌리기 안내, 다음 한 수를 점선으로), 일시정지, 설정(소리 · 잔잔한 움직임 · 실 모양 6종 · 수틀 2종, 별로 해금), 게임 방법.
- 입력: 끌어 놓기 · 탭으로 고르고 탭으로 놓기, 키보드(방향키 · Enter · U · H · Esc · Backspace), 게임패드(십자키 + A / B / X / Y / Start).
- 진행 저장: `localStorage['looseends.v1']`. 서버 동기화 없음.

## 화면

- 16:9 기준: 왼쪽 판(이동 · 목표 · 별 기준 · 남은 줄 · 꼬임 수), 오른쪽 판(안내 · 힌트 · 되돌리기 · 다시 하기), 수틀은 두 판 사이 가운데에 최대로. 세로 휴대폰(가로 640px 이하 또는 가로세로비 5:4 이하)은 판 정보를 아래로 모아 줄여 맞춘다.
- 실 · 핀 · 구멍 · 꼬임 매듭은 움직이고 휘어야 해서 캔버스로 그린다(굵기 · 꼰 결 · 밝은 면 · 가장자리 테 · 그림자 · 놓으면 튕김).

## 아케이드

- 순위 점수 = 단계별 최고 점수 합(단계당 최대 2,800) + 끝없는 실 푼 수 × 250(최대 400판). 서버 상한 250,000.
- 일반 퍼즐을 풀면 브라우저에 진행을 저장하고 `hk:live`로 현재 점수를 알린다. 순위 점수는 본편 40단계를 모두 완료했을 때(`hk:score`) 또는 아케이드에서 「기록 남기고 나가기」를 선택했을 때 저장한다. `HKEmbed`는 부모 출처와 창을 검사한다.

## 파일

- 틀: `web/games/looseends.html` · 본체: `web/games/embed/looseends.html`
- 규칙 · 풀이기 · 생성기: `web/games/embed/looseends/rules.js` (Node 시험과 공용)
- 본편 40판: `web/games/embed/looseends/levels.js`. 일괄 제거 규칙으로 바꿀 때 기존 판 배치를 유지하고 40단계 목표만 8수로 다시 계산했다. `node scripts/build-looseends-levels.cjs`는 현재 규칙으로 판 배치를 새로 생성한다.
- 렌더링 · 입력 · 저장 · 연동: `web/games/embed/looseends/game.js`, 모양: `style.css`

## 검증

```sh
node scripts/test-looseends.cjs
```

규칙, 꼬임(감김 · 풀림 · 감긴 채 안 빠짐), 본편 40판 모두 풀이 가능 · 목표 수 일치 · 풀이 재생 클리어, 꼬인 상태에서 힌트 풀이, 처음부터 꼬인 판 생성, 점수 상한, 생성기 결정성을 검사한다.
