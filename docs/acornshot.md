# 도토리 새총단 (`acornshot`)

옆에서 보는 2D 물리 새총 퍼즐. 원작의 캐릭터·이미지를 사용하지 않는 도토리와 밤도깨비 테마.

## 플레이

- 도토리를 뒤로 당겨 놓아 발사한다. 점선은 초기 궤적을 안내한다.
- 기본 / 폭탄 / 세 갈래 도토리. 특수 도토리는 비행 중 터치 또는 Space로 한 번 사용한다.
- 나무·얼음·돌은 강도와 질량이 다르며 충돌·낙하·폭발로 부서진다.
- 위층이 있는 층의 적을 처치하면 잠시 뒤 그 층의 기둥이 벌어지고, 받침을 잃은 지붕과 위층의 적이 실제 물리로 떨어진다.
- 기둥이나 받침판이 부서져도 위층 전체의 물리를 깨운다. 마지막 적을 처치한 뒤에는 움직이는 구조물 잔해가 가라앉은 다음 결과를 표시한다.
- 붕괴 중 떨어진 구조물은 무게·낙하 높이·충돌 속도에 따라 착지한 조각과 주변에 피해를 주고, 먼지·파편과 충격음을 낸다.
- 강한 첫 명중을 짧게 강조하고, 재질별 파편은 바닥에 닿아 튕긴다. 큰 충격에는 충격파가 퍼지며, 한 발로 조각을 3개 이상 부수면 연쇄 수가 표시된다. 동작 줄이기 설정에서는 화면 흔들림·순간 멈춤을 끈다.
- 구조물·도토리·적은 보이지 않는 좌우 벽·천장과 매 단계의 실제 도형 기준 위치 보정으로 항상 화면 안에 머문다(벽은 피해를 주지 않는다). 파편·먼지·점수 글자도 화면 안에서만 그려진다.
- 적은 회전한 귀까지 포함해 화면 좌우·위 경계 안에 머무르며, 경계에 닿으면 안쪽으로 약하게 튕긴다. 화면 밖 이탈로 처치 점수를 얻지 않는다.
- 8개 스테이지, 순차 해금, 별 1~3개, 단계 재도전.
- 난이도(2026-11-20): 적 체력(`enemyHp`)과 구조물 강도(`blockHp`)를 단계별로 올렸다. 적은 약한 충돌로는 죽지 않고 낙하·폭발 같은 강한 충격이 필요하다. 별 3개는 탄환의 60% 이하로 깨야 하며, 필요한 발수는 단계별로 1 → 2 → 3 → 3 → 4 → 5 → 3 → 5발이다(단순 탐색 기준, 사람은 더 걸린다). 7단계는 6단계보다 쉬우며 추가 조정이 필요하다.
- 지형(2026-11-20): 단계마다 `ground` 꺾은선으로 언덕·절벽·계단·골짜기·바위 둔덕이 다르다(`physics.js`의 `LEVELS`). 지형은 정적 물리 몸체이며, 망루마다 평평한 받침이 깔려 어떤 지형에서도 안정적으로 선다. 화면 그리기는 단계 `theme`(meadow·cliff·stone·ice·castle)에 따라 흙·풀 색을 바꾸고, 궤적 미리보기와 파편은 실제 지형 높이에서 멈춘다. 지형은 이 게임 고유의 오리지널 배치다.
- 3단계부터 두 망루를 공략한다. 후반에는 층수와 재질 강도가 높아지고, 최종 도토리 성채는 도토리 3개로 돌탑을 포함한 6마리를 처치해야 한다.
- 키보드: 좌우 각도, 위아래 힘, Space 발사·능력, Esc 일시정지.
- 터치·포인터 취소 시 발사하지 않는다. 숨겨진 탭에서는 자동으로 일시정지한다.
- 소리는 사용자가 켠 경우에만 Web Audio로 합성한다.

## 기록·아케이드

- 단계별 최고 점수와 별: `localStorage['acornshot.v1']`. 브라우저별 저장이며 서버 진행 동기화는 하지 않는다.
- 아케이드 순위: **한 단계의 점수**, 서버 상한 20,000점.
- 밤도깨비 1,000점, 나무 120점, 얼음 150점, 돌 200점, 클리어 2,000점, 남긴 탄환 1개당 1,000점.
- 성공·실패 결과 모두 한 번 제출. 단계 선택으로 나가면 현재 점수를 제출한다.
- 기존 `HKEmbed` 틀의 `hk:ready/start/live/score/pause/resume/restart` 규약 사용. 부모 출처와 창을 검사한다.

## 파일

- 틀: `web/games/acornshot.html`
- 본체: `web/games/embed/acornshot.html`
- 렌더링·입력·상태·저장: `web/games/embed/acornshot/game.js`
- 120Hz 고정 간격 물리·스테이지: `web/games/embed/acornshot/physics.js`
- 로컬 Matter.js 0.20.0 MIT: `web/games/embed/acornshot/vendor/`
- 원본 Canvas 드로잉으로 배경·캐릭터·구조물을 그린다. 이미지 생성 서비스나 외부 CDN 런타임 의존 없음.

## 검증

```sh
node scripts/test-acornshot.cjs
```

발사 전 탑 안정성, 8개 스테이지 실제 탄도 해법 탐색·재현, 소진 실패, 결과 단일 발생, 점수 범위, 능력 일회성과 분열을 검사한다.

백엔드 가상환경에서 `tests.test_acornshot_static`와 `tests.test_moonshot_static`를 실행하면 등록·틀·로컬 의존 파일·점수 상한·기존 게임 순서를 검사한다. 환경 파일을 읽지 않게 저장소 바깥에서 `PYTHONPATH`를 backend로 설정한다.

직접 실행: 정적 서버의 `/games/embed/acornshot.html`. 로그인 포함 아케이드 실행: `/games/acornshot.html`.

### 2026-11-20 검증 결과

- 물리 테스트: 8개 단계 모두 실제 발사 해법으로 클리어, 탄환 1~2개 사용. 단계별 5,120~13,130점.
- 백엔드 연동·기존 게임 검사: 21개 중 18개 통과, 기존 숨김 게임 관련 3개 건너뜀.
- 브라우저: 마우스 드래그 클리어(5,120점·별 3개), 새로고침 후 기록·해금 유지, 키보드 발사, 일시정지 중 좌표 정지 확인.
- 모바일: 844×390 터치 드래그로 실제 클리어, 390×844 세로 메뉴 가로 넘침 없음·모든 단계 버튼 화면 안 표시 확인.
- 실제 `HKEmbed`를 사용하고 서버 컨텍스트만 시험 대역으로 교체해 시작·일시정지·이어 하기·결과 단일 제출·재시작 확인. 인증된 운영 서버의 점수 API 호출은 이 로컬 검증에 포함하지 않음.
