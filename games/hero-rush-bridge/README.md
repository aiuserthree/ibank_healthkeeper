# Hero Rush Bridge

A single-file 3D crowd-runner (Three.js r160 from cdnjs). Open `index.html` in a browser.

- Steer with drag, or ← → / A D.
- Blue gates (+N, ×N) add heroes, red gates (−N, ÷N) remove them.
- 8 levels, each adding a trap: saw blades, gaps, swinging hammers, sliding saws, spinning bars, crushers, rolling boulders, cannons.
- Every level ends with an enemy army (1:1 trade) and a boss the surviving crowd climbs and topples.
- Progress and stars are kept in `localStorage`.
